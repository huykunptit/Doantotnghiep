--- Production (Docker) ---

1) Đảm bảo 3 PDF đã nằm trong ai-service/rag/textbooks/

2) Rebuild image nếu container chưa có chromadb:
   docker compose build ai-service
   docker compose up -d ai-service

3) Index (không tải GitHub; lần đầu tải thêm model embedding ~80MB):
   docker exec lms_ai_service python -m rag.ingest --demo-pack

4) Kiểm tra:
   docker exec lms_ai_service python -c "from rag.store import get_collection_stats; import json; print(json.dumps(get_collection_stats(), ensure_ascii=False, indent=2))"

ready=true, document_count=3 là xong. Chatbot sinh viên tự dùng RAG.
