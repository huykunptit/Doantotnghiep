State machine: draft → pending → published / rejected
Publish Flow
Instructor tạo khóa học └── status: draft │ ▼ Instructor submit review └── status: pending │ ▼ Admin duyệt ├── Approve → status: published → Sinh viên thấy trên marketplace └── Reject → status: rejected → Kèm lý do → Instructor sửa lại → pending

4
Sơ đồ luồng tổng thể theo Role
ADMIN
Đăng nhập → Quản lý User (tạo/sửa/xóa, gán role) → Duyệt khóa học (pending → published/rejected) → Cấu hình AI provider + quota → Quản lý cấu trúc học vụ (Institution → ClassSection) → Monitor thi real-time (live dashboard) → Xem/quản lý đơn hàng (Orders) → Cấu hình Site Settings (SMTP, branding...)
INSTRUCTOR
Đăng nhập → Tạo Course (draft) → Thêm Section → Thêm Lesson (video/text/quiz/...) → Submit for review (pending) → [Admin approve] → published → Tạo Question Bank → Question Groups → Questions → Tạo Quiz/Exam từ Question Bank → Nhập điểm sinh viên (GradeEntry) theo GradeComponent → Xem dashboard doanh thu + danh sách sinh viên → Sử dụng AI để generate nội dung / đề thi
ACADEMIC_MANAGER
Đăng nhập → Tạo cấu trúc: Institution → Unit → Program → Major → Specialization → Tạo Cohort → AdministrativeClass → Curriculum → Tạo AcademicYear → Term → Tạo ClassSection (course + term + cohort + instructor) → Enroll sinh viên vào ClassSection (manual hoặc CSV import) → Theo dõi bảng điểm, báo cáo học vụ
STUDENT — Hai luồng chính

LUỒNG 1: MARKETPLACE (Tự mua)

Đăng ký → Xác minh email → Đăng nhập → Duyệt danh mục / tìm khóa học → Xem chi tiết course (preview lessons) → Thêm vào giỏ / Thanh toán (PayOS) → Enrolled → Học bài (video/text/scorm) → Làm quiz bài học → Hoàn thành 100% → Nhận Certificate → Đánh giá (review) khóa học

LUỒNG 2: HỌC VIỆN (Được enroll)

Đăng nhập (tài khoản do admin tạo) → Xem lịch học / ClassSection được gán → Học bài học theo lịch → Điểm danh (QR code offline sessions) → Thi cuối kỳ (ExamEnrollment) → Nhận điểm (GradeEntry) → GPA tích lũy cập nhật → Xem bảng điểm / transcript
Ngoài ra (cả 2 luồng): → AI Chatbot (hỏi đáp học thuật) → Upload CV → Career Recommendation → Q&A trong khóa học → Nhận Notification
ADVISOR
Đăng nhập → Xem danh sách advisee (sinh viên được phụ trách) → Phát hiện sinh viên nguy cơ (điểm thấp, vắng nhiều) → Xem bảng điểm chi tiết từng sinh viên → Xem tiến độ học tập

Nghiệp vụ cần test trọng điểm
Nghiệp vụ Độ phức tạp Ghi chú cho Tester
Luồng thi + Proctoring CAO Timer, auto-save, vi phạm cam, force-stop, gia hạn thời gian
Thanh toán PayOS + Webhook CAO Cần mock webhook hoặc sandbox PayOS. Kiểm tra chữ ký HMAC
Nhập điểm + GPA CAO Trọng số phải = 100%, làm tròn điểm, edge case: 0 điểm / vắng
SCORM package CAO xAPI tracking phức tạp, hoàn thành/không hoàn thành, score
Import sinh viên CSV TRUNG BÌNH Validate format, duplicate handling, rollback khi lỗi giữa chừng
Đăng ký + xác minh email TRUNG BÌNH Email cần được gửi, link verify có TTL, resend email
Google OAuth TRUNG BÌNH Cần Google credentials test env. FirstOrCreate user flow
AI chat / generate TRUNG BÌNH Phụ thuộc API key và quota. Test khi hết quota (quota exceeded)
Attendance QR TRUNG BÌNH QR hết hạn sau X phút, không điểm danh được 2 lần, sai địa điểm
Duyệt khóa học THẤP State machine: draft→pending→published/rejected. Notification đến instructor
Certificate cấp & xác minh THẤP Credential ID phải unique, public endpoint không cần auth
Q&A + Review THẤP Chỉ enrolled mới review được. Like/dislike idempotent
